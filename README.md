# 👗 Zaalima - Fashion E-commerce SaaS Platform

A modern multi-tenant SaaS platform for fashion brands to manage their online stores.

**Live GitHub:** https://github.com/sidhu2809/zalima-ecommerce-saas

### ✨ Features
- 🏬 Multi-Store Management - Create & manage multiple fashion stores
- 🛍️ Live Product Display - Add product and see instantly in store
- 📦 Product Management - Add, Edit, Delete fashion products
- 🎨 Modern UI - Built with Tailwind CSS + Glassmorphism
- ⚡ Fast - Vite + React + TypeScript
- 🔌 REST API - Node.js + Express backend

### 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** In-Memory (Can be upgraded to MongoDB)
- **Tools:** Git, GitHub

### 🚀 How to Run Locally
```bash
# Clone the repo
git clone https://github.com/sidhu2809/zalima-ecommerce-saas.git
cd zalima-ecommerce-saas

# Backend
cd backend
npm install
npm run dev
# Runs on http://localhost:5000

# Frontend (new terminal)
cd frontend
npm install
npm run dev
# Runs on http://localhost:5173
